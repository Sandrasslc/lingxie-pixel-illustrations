## 品牌不变量

### 1. 蟹红与黑色骨架

主画面以蟹红、珊瑚红和黑色为识别骨架。可从参考 Logo 取色；下列色值只是构建提示词或排版时的起点，不是印刷专色：

- 主蟹红 `#F12B22`
- 珊瑚红 `#F96863`
- 深红阴影 `#D91F18`
- 墨黑 `#111111`
- 暖白 `#FFF9EC`，仅在内容适合时使用

蓝、橙、黄、绿色可作为状态、能量或重点提示色，但面积应明显小于红色。背景可以是夜景、游戏地图、舞台、实验室、自然场景或纯色，只要红黑识别仍然成立。

### 2. 真实的像素语言

目标是 8/16-bit 游戏美术感，不是给普通插画叠一层马赛克滤镜。

- 用清晰像素簇塑造轮廓和体积。
- 曲线呈有节奏的阶梯边缘，不使用柔滑矢量曲线。
- 每个红色区域通常只用 2 至 4 个明暗色阶。
- 阴影使用硬边色块、有限抖色或逐格过渡。
- 黑色描边保持一致粗细，并随画布规模成比例放大。
- 允许像素 UI、状态条、物品栏、对话框、关卡标识等游戏语言，但只在它们帮助表达内容时使用。

避免抗锯齿柔边、摄影景深、霓虹光晕、玻璃拟态、光滑 3D 塑料、厚涂、水彩和铅笔草图。不要混用多种不相容的像素密度。

### 3. Logo 与左上角品牌锁定区

Logo 的识别来自对称螃蟹结构、分区红色和紧凑字标。像素化时要保留整体轮廓与左右平衡，不逐像素临摹原图的平滑渐变。

默认优先考虑左上角品牌锁定区，继承参考周报 Banner 中值得保留的处理方式：

- 小而清楚，周围有足够留白。
- 与主标题形成两个层级，Logo 不应比标题更抢眼。
- 可组合像素螃蟹图标与“灵蟹”“灵蟹创作”或 `SoloEnt`；只使用与当前语言和版面匹配的版本。
- 背景复杂时给锁定区加入单色像素底板或 HUD 框，确保对比度。
- 极窄画幅可以把锁定区移到其他角落，但仍应像一个完整签名，而不是散落文字。

品牌名必须逐字正确。若图像模型无法可靠呈现字标，应缩短为可验证的版本、保留明确的角标区域，并在后续精确排版中加入字标，不能接受近似乱码。

### 4. 螃蟹 mascot

Mascot 继承 Logo 的圆润躯干、对称钳子、红色分区和黑色像素描边，同时可以拥有表情、四肢、道具和动作。

- 让动作服务本次内容，例如举起更新模块、开启活动入口、递交文档、探索地图或组织队伍。
- 保留至少一个容易识别的螃蟹特征组合：双钳、横向身体、眼柄和红色分区。
- 表情可以变化，身体识别不能漂成龙虾、蜘蛛、机器人或普通圆形角色。
- 主场景已经有大型 mascot 时，Logo 区仍保持简洁，不再堆叠第二个抢眼角色。

## 内容到场景的映射

先从正文找出“谁在做什么、发生了什么变化、读者接下来要做什么”，再选择场景。以下只是启发，不是固定模板：

| 内容类型 | 可用叙事方向 |
| --- | --- |
| 周报或更新日志 | 升级关卡、版本工坊、补给站、任务结算、信息列车 |
| 活动招募或发布会 | 集结营地、开放关卡、舞台、传送门、多人大厅 |
| 新模型或新功能 | 装备锻造、芯片舱、技能树、模块装配、能力解锁 |
| 教程或方法论 | 地图导航、逐关教学、工具箱、解谜台、任务路径 |
| 复盘或里程碑 | 通关画面、奖杯台、航海日志、里程碑地图 |

选择与正文最强动词相符的方向。不要因为参考图里有日历或纸张，就把所有主题都画成周报板。

## 构图与文字

- 先保证一个清晰焦点，再安排标题、品牌锁定区和辅助信息。
- 为标题保留完整的像素化负空间，不让钳子、道具或高对比纹理穿过字面。
- 横版可用“标题区 + 主场景”或“中央场景 + 两侧信息”；方形和竖版优先让 mascot 成为中心。
- 正文配图不必重复文章标题，可用无文字叙事；活动物料和封面则通常需要短标题。
- 一张图只承载一个主标题。标签越多，场景元素越应减少。
- 中文、英文和数字都要逐字核验，禁止自造日期、版本号、价格、网址或功能名。

## 禁止项

- 固定奶油白底，或把白底误认为品牌必选项。
- 每次复刻办公室、日历、纸张或同一个 mascot 姿势。
- 只把普通插画低清化，缺少真正的像素簇和阶梯轮廓。
- 用红色渐变和圆角矢量代替像素语言。
- 让装饰图标比输入内容更重要。
- 复制参考图中的完整构图、标题或活动信息。
- 错写“灵蟹”“灵蟹创作”或 `SoloEnt`。

## 验收清单

交付前逐项确认：

- [ ] 比例和信息密度适合最终发布位置。
- [ ] 一眼能看懂本次内容的主题与主动作。
- [ ] 场景由本次输入推导，且没有沿用固定模板。
- [ ] 蟹红/珊瑚红、黑色像素描边和 8/16-bit 语言同时存在。
- [ ] Logo/品牌锁定区清晰，左上角方案在适合时得到优先考虑。
- [ ] mascot 是可识别的灵蟹，并参与场景叙事。
- [ ] 像素边缘清晰，没有平滑插值或风格漂移。
- [ ] 所有文字、数字、日期与品牌名逐字正确。
- [ ] 缩略图下主标题和主体仍有辨识度。
- [ ] 没有水印、无关品牌、乱码或用户未要求的口号。
